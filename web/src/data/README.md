# Data layer

Every number and case on the site comes from a file in this repository. Nothing is
typed into JSX.

| file | what | source |
|---|---|---|
| `generated/results.json` | metrics, per-query first ranks, K sweeps, error cases, hubness graph, λ grids, training curves | `reports/results/*.json`, `*.csv`, `data/manifests/manifest_info.json`, generated by `web/scripts/build_data.py` |
| `generated/figures.json` | HPCP matrices, rotation bars, cost matrices and DTW paths **decoded from committed plots** | `reports/figures/*.png`, generated by `web/scripts/extract_figures.py` |
| `results.ts`, `figures.ts` | typed access to the two JSON files | — |
| `benchmark-data.ts` | the four benchmark runs, kept separate; labels; published context | `benchmark*.json`, `notes/literature/novelty_assessment.md` |
| `retrieval-cases.ts` | development protocol, error cases, the P_797406 case study | `hybrid_dev*.json`, `error_cases*.csv`, `reports/error_analysis.md` |
| `architecture.ts` | TCN shapes and parameter count (checked against the training summary in tests) | `models/tcn_encoder.py`, `configs/base.yaml` |
| `hubness.ts` | hub graph and correction | `hubness_dev.json`, `hubness_correction*.json` |
| `experiment-history.ts` | the research log | `git log`, `notes/decisions.md` |
| `project.ts` | dataset, reproducibility, limitations, future work | `DATASET_CARD.md`, `README.md` |

## Decoded figures

Da-TACOS HPCP features are CC BY-NC-SA and are never committed, so the site cannot
show them directly. The committed matplotlib figures are inverted instead: each pixel
is matched to the nearest entry of the figure's colour map (magma / viridis_r), giving
a colour-scale position in [0, 1]. These values are **relative** (per-panel scale,
256 levels), not feature values, and every figure caption says so.

Checks (in `src/test/`): recomputing profile-rotation cosines from the decoded HPCP
picks the published best shift for all four pairs, and subsequence DTW on the decoded
cost matrices lands within 5 frames (mean) of the published red paths.

## Regenerate

```bash
pip install numpy matplotlib pillow      # or the project venv
python web/scripts/extract_figures.py
python web/scripts/build_data.py
```

CI fails if the committed output differs from a fresh run.
